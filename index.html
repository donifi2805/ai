Panduan Integration Endpoint api4.php (AkrabOke)

Endpoint api4.php mendukung transaksi produk reguler, produk opendenom (bebas nominal), serta sistem Pascabayar / PPOB 2-Tahap (Inquiry Cek Tagihan & Payment Token).

Tahap 1: Get Product / Katalog (`action=list` atau `action=produk`)

Mengambil daftar produk aktif beserta harga yang sudah termasuk markup akun Anda.

Endpoint: https://dt17.store/h2h/api4.php

{
  "action": "list",
  "api_key": "dt17_e1f063f90349bf69416c598f4c3d9529"
}

[Respon Sukses]:

Tahap 5: Hit Beli Produk Cek / Inquiry PPOB (`action=cek`)

Langkah 1 PPOB: Cek tagihan PLN Pasca, BPJS, PDAM, dll. Gunakan kode Cek (awalan C misal CPAM atau memuat kata CEK misal PKTCEKCUAN). Parameter tujuan menggunakan tujuan atau target. Backend akan otomatis melakukan polling retry selama 10 detik sampai data tagihan diperoleh.

{
  "action": "cek",
  "kode": "CPAM",
  "tujuan": "12345678",
  "api_key": "dt17_e1f063f90349bf69416c598f4c3d9529"
}
Panduan Penanganan Respon Inquiry:
1. Backend api4.php telah dilengkapi fitur Auto-Polling Retry (re-check otomatis hingga 5 kali / 10 detik ke server pusat).
2. Jika status = true: Data tagihan (TTAG) dan payment_token sudah berhasil didapatkan. Anda dapat melanjutkan ke Tahap 6 untuk eksekusi bayar.
3. Jika status = false (Pesan: "Masih Diproses"): Ini terjadi jika server pusat membutuhkan waktu lebih dari 10 detik. Silakan lakukan hit ulang action=cek dengan parameter yang sama setelah 2-3 detik hingga tagihan keluar.

[Respon Sukses Cek Tagihan (Final Result)]:

{
  "status": true,
  "message": "Pengecekan Berhasil",
  "data": {
    "ref_inq_pandawa": "INQ-20260726200000123",
    "tujuan": "12345678",
    "payment_token": "cmVzZWxsZXIxMjN8QlBBTXwxMjM0NTY3OHxJTlEtMjAyNjA3MjYyMDAwMDAxMjM=",
    "keterangan": "SUKSES Cek PDAM A/N BUDI | TTAG: 50000"
  }
}

Tahap 6: Hit Cek & Bayar Payment Token (`action=bayar` + `payment_token`)

Langkah 2 PPOB: Pelunasan tagihan PPOB hasil pengecekan Tahap 5 dengan mengirimkan parameter payment_token. Token berlaku selama 10 menit. Total harga yang dipotong dari saldo adalah (Tagihan Hasil Cek + Admin Server + Markup).

{
  "action": "bayar",
  "payment_token": "cmVzZWxsZXIxMjN8QlBBTXwxMjM0NTY3OHxJTlEtMjAyNjA3MjYyMDAwMDAxMjM=",
  "ref_id": "TRX_PPOB_PAY_001",
  "api_key": "dt17_e1f063f90349bf69416c598f4c3d9529"
}

[Respon Sukses Eksekusi Bayar]:
